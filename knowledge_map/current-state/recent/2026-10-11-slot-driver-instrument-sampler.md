## 2026-10-11 — The slot driver samples Studio's link/heal counters at 1 Hz (#693)

`slot_driver.py` now writes `instrument-1hz.csv` (a read-only `fetch_instrument_status` every second from the Run entry to the closed run; `--instrument-hz 0` turns it off) and `post-instrument.json` at the end, beside the existing `pre-instrument.json`. The columns are Studio's own `link.ingress_errors_per_s` / `ingress_errors_avg_per_s` / `ingress_errors_warn` and `link.rx_heal` counters (auto_resets, episodes, failed_episodes, flag_clears, tries, gave_up, fs_seen, nofs_frames, nofs_lines); a host Studio has no `link`, so its cells are empty. **They are not the producer's `PzReceiverLineErrors`**: that counter comes from the board owner's snapshots with Studio stopped. Made for the 1 kHz slot, where the receiver line errors are the open question ([[current-state/recent/2026-10-11-adjustable-run-fps]]). Tests: `InstrumentSampler` in `tools/ring_vs_ssd/test_ring_vs_ssd.py` (row contents, empty cells on an error reply, the sampler asks for nothing but `fetch_instrument_status`).
