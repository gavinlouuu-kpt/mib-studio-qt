## 2026-10-20 — R3 Inspect on the kit (#717 B3a)

Track B (#717) step B3a, the UI half of R3 Inspect (#269), on
`feat/egrabber-workspace` and from the review commands that exist today (no
contract change; B3b on `develop` adds review ABI 3, which B3c wires in).

- `ReviewPanel` is laid out as the Penpot R3 board on `@mib/ui`: a toolbar
  with the sub-views Scatter / Records / Frames and the set, a second row
  with the file actions, every export, the overlay and ROI; the sub-view on
  the left (the canvas scatter in a `Card`, the thumbnail grid, the paged
  records table on the kit `DataTable`); on the right the selected record
  and what produced the stored results (`inspect/InspectCards.tsx`).
- The record is named `frame N · object M` (no invented id). Its image is
  a Raw / Contour / Mask crop (the backend draws the overlay, the client
  cuts the bounding box, `inspect/packetCrop.ts`) or the full frame with
  the toolbar's overlay and ROI. Views a record cannot show are disabled
  with the reason; Previous / Next record and Record details (the frame
  viewer).
- The Stored card names the core, snapshot, calibration and px→µm the
  stored results came from; E-LUT "Not available" until B3c; reprocessing
  writes a new file (the Regenerate masks dialog) and no history is listed
  (#754).
- The scatter and histogram draw with the kit's colours
  (`charts/chartPalette.ts`), on screen and in exports.
- Every pre-B3a control stays reachable; the `reviewIpc` golden is
  unchanged. Kit requests (canvas inspect mode for `AreaDeformChart`, an
  image input for `CellImage`, `DataTable` paging, an optional
  `RecordIdentity` id) are on #715.

Tests: `inspect/inspectModel.test.ts`, `inspect/InspectView.test.tsx`. See
[[YofoReview]].
