## 2026-11-02 — F-1: full-recording native population analysis (#808)

F-1 of the FlowJo fold-in (goals F01, F04, F05, F08, F16). The native evaluator no
longer refuses sources over 10,000 events or files over 64 MiB.

- **Chunked columns.** `RecordingColumns` reads area, deformability and
  youngsModulus from `/valid_frames/metadata` and `/invalid_frames/metadata` in
  65,536-row chunks through `Hdf5Service::readMetadataColumns`.
- **One evaluator.** `PopulationGates` (the graph compiler moved out of
  `SourceAnalysis.cpp`) and `ColumnarEvaluation` evaluate the population DAG chunk by
  chunk with unchanged tri-state semantics into two-bit `TriStateBits` membership
  (`MembershipSet`, keyed to source identity + graph revision, cached 4 deep in
  `ReviewSession`). F-source/1 evaluation uses the same evaluator over in-memory
  columns.
- **Statistics.** Exact, from every selected finite value, through the shared
  `reduceMeasuredValues` (type-7 quantiles, n−1 SD, CV, geometric mean).
- **Fingerprint.** Streamed full-file SHA-256 at any size, cached per open generation.
- **Bounds.** Columnar: ≤2^32−1 events, bitsets ≤256 MiB, ≤2^26 exact-statistics
  values. Keyed path: 1,000,000 events / 16,777,216 node-events. F-source/1 JSON
  rows: 100,000 events. Each refusal names its bound.
- **Contract.** Review ABI 10: `review_analyze_population` returns bounded results:
  `rows` is a page, plus `populations`, `histogram`, decimated `scatter`,
  `membershipKey`, `evaluation`. Geometry nodes and youngsModulus are now accepted.

Proof: `review.population_scale` (300,000 events, 73.3 MiB file written by the
production writer; oracle-exact counts at every population; analysis peak RSS
growth 1.9 MiB) and `analysis.columnar` (columnar == keyed at every node and chunk
size). Evidence class: real backend, synthetic file. Remaining: columnar source
handles for the `AnalysisHost` workspace path (still JSON rows, ≤100k), ReviewSession
open still materializes per-row browse metadata, FCS import (F-2), real-recording run.
See [[services/AnalysisWorker]], [[services/ReviewSession]].
