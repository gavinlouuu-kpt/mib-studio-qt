Review fixes (#823; F15, F04, F16):
- **Hang.** `$DATATYPE I`, `$PnB 64`, `$PnR` in (2^63, 2^64) overflowed the
  power-of-two loop to 0 and never ended. The mask is now closed-form and bounded by
  the bit width; "no mask" is `std::nullopt`, so `$PnR` 1 (values 0..0) masks to 0
  as the FCS 3.1 spec intends instead of meaning "unmasked".
- **Fingerprint claim.** The descriptor said the SHA-256 is re-verified on every
  evaluation; it was cached by path, size and write time and not re-checked after
  the scan. `lendFcsColumns` now fences before and after the scan, and `retention`
  states what is verified (no per-evaluation re-hash; a size- and mtime-preserving
  rewrite is not detected).
- **> 64 parameters.** `SourceCore` refused columnar sources above 64 parameters
  the reader accepted (≤ 1,024); the limit is now 1,024 with lazy columns, and
  JSON materialization is bounded by cells.
